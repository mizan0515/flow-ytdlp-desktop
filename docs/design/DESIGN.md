# Flow desktop design

Outcome: paste a URL, choose the desired media, download, and recover failures.
Windows desktop, Korean first, minimum viewport 960 x 640. Quiet light canvas,
deep navy sidebar, indigo primary action, restrained borders, generous spacing.
The first screen is the usable download form, with no fabricated tasks or metrics.
Use Segoe UI/Malgun Gothic, visible focus, semantic labels, keyboard operation,
text status in addition to color, reduced motion and 200% zoom support.
Keep basic controls to URL, output profile, folder, and subtitles. Searchable
full engine options live in a drawer. Every setting has an explicit enabled
state; a blank/unselected value inherits the engine default. Preserve repeated
option order and disclose sensitive/code-executing options before execution.
Loading, no results, empty queue, validation error, network failure, cancellation,
postprocessing, and completion must have explicit actionable states.
Do not claim file success until the engine finished and output exists.
Do not silently activate cookie sources, third-party plugins, or external commands.
