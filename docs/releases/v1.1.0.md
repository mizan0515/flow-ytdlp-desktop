Windows용 yt-dlp GUI Flow 1.1입니다. 기본 화면은 간결하게 유지하고, 전체 옵션과 타임라인 구간 다운로드를 제공합니다.

## 설치와 실행

1. **Flow-1.1-Windows.zip**을 받아 압축을 풉니다.
2. 첫 사용 전에 **Setup-Engine.cmd**를 한 번 실행합니다. 공식 yt-dlp·FFmpeg·Deno를 SHA256 확인 후 앱 폴더에 준비합니다. 관리자 권한이나 Python 설치가 필요하지 않습니다.
3. **Flow.exe**를 실행합니다.

Windows x64, .NET Framework, Microsoft Edge WebView2 Runtime을 사용합니다. 구성요소 설치에는 인터넷 연결이 필요합니다.

## 주요 기능

- 타임라인 시작·종료 손잡이로 구간 늘리기·줄이기, 선택 구간 통째로 이동
- 확대·축소·전체 맞춤, 커서로 경계 지정, 시간 직접 입력과 키보드 미세 조절
- 선택 구간 다운로드와 프리셋 저장·복원
- yt-dlp 2026.10.21의 323개 옵션 정의 / 별칭 포함 394개 플래그 검색·편집
- 영상·오디오·MP3, 작업 목록, 중단·재시도, 기록 복원

## 검증

공개 릴리스는 GitHub Windows 러너에서 소스와 구성요소를 준비하고 빌드·프런트엔드·실제 다운로드/변환 검사를 통과한 뒤 생성합니다. GUI ZIP에는 사용자 데이터와 미디어 엔진 바이너리를 포함하지 않습니다.

실제 Windows UI는 로컬에서 19개 확인 항목을 통과했습니다. 12초 테스트 영상의 2초 구간을 선택해 실제 2.000초 미디어로 저장되는 것을 확인했습니다. 모든 사이트·계정·옵션 조합의 성공을 의미하지는 않습니다.
